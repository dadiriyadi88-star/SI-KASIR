Belum Terhubung

Cara Menghubungkan Firebase (Otomatis Mengenali Format Apa Saja):

  1. Buka Firebase Console (console.firebase.google.com), pilih project Anda.
  2. Klik icon Gerigi ⚙️ (Project settings) -> Scroll ke bawah ke bagian Your apps (Web app).
  3. Salin utuh potongan kode const firebaseConfig = { ... }; atau format JSON-nya.
  4. Tempelkan langsung pada kolom di bawah ini lalu klik tombol Simpan & Hubungkan Firebase.
